# applyGain(gain, optionsopt) → {this}

Scales RGB channels into the HDR range by a gain factor. This is the lightweight replacement for the removed colorjs.io based convertPixelToRec2100_hlg: no gamut conversion, just a linear boost. Values >1 only become visible as HDR on a canvas configured with toneMapping: { mode: "extended" } (see getHdrOptions()), otherwise they clip to SDR white.

Alpha is preserved by default.

When WASM acceleration is enabled via setWasmEnabled(true) (experimental, disabled by default) and the image is large enough, the loop runs in the inlined WASM kernel with transparent fallback to JS.

Parameters:
Name Type Attributes Default Description
gain number | Array.<number>

Uniform gain or per-channel [r, g, b] gain. E.g. 2 doubles brightness into HDR headroom, 0.5 dims to half.
options object <optional>

Options.
preserveAlpha boolean <optional>
 true

Leave alpha untouched when true.
useWasm boolean <optional>

Force the WASM (true) or JS (false) path for this call. Defaults to the global flag from setWasmEnabled().
