HDR canvas verification

Renders a synthetic UltraHDR texture next to raw value patches. The canvas is read back directly via copyTextureToBuffer, so the measured values are what was actually written to the framebuffer. Patches expected: 1.0, 1.5, 2.5, 4.0 and 8.0 (SDR reference white relative, scene linear). The patches are the HDR proof: they are written above 1.0 into a float16 canvas. The texture currently renders as its tone mapped SDR base - Chrome does not apply UltraHDR gain maps on copyExternalImageToTexture uploads yet, which the textureHDR field reports informationally.
