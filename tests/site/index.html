WCG and HDR are reported separately:
  • SDR: neither WCG nor HDR is reported.
  • WCG-only (e.g. Safari, Firefox on macOS): WCG checks pass, HDR checks fail.
  • HDR: HDR checks pass (HDR usually includes WCG).

Three.js HDR

HDR support for the canvas element needs the browser flag enable-experimental-web-platform-features to be enabled. For example, open chrome://flags#enable-experimental-web-platform-features in Chrome to activate it.

The model's texture is a plain SDR JPEG (this Uranium GLB does not carry an UltraHDR texture), so it renders within the SDR range. Tone mapping isn't enabled. If your browser doesn't support HDR canvases you'll just see a model with a black texture.

HDR canvas verification

Renders a synthetic UltraHDR texture and raw value patches (1.0, 1.5, 2.5, 4.0, 8.0 SDR white relative) and reads the canvas back to prove that values above 1.0 reach the framebuffer. Also available as an automated test: npm run test:hdr. Open the verification page.
